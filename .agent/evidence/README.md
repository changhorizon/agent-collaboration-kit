# Evidence（原件索引）

这里只存重要调查、检查和审阅的可定位索引。原始日志无需整份复制；敏感原件存获授权的受控位置，此处保存脱敏副本或指针，注明处理方式。

每个关键主张记录：

- 主张与关联的 task / message / decision ID：
- 对象（环境、服务、进程、制品）与版本（代码、镜像、依赖、工作树）：
- 采集命令/方式、UTC 时间及原件位置：
- 原件可读取者与脱敏方式：
- 证明范围与未覆盖事项：
- 检查的判据和它何时会失败；未验证写未验证：

不要用消息摘要或 Project State 替代原件，也不把假设记为证据。全称断言要注明搜索/测试覆盖口径。
