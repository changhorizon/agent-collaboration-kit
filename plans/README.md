# 本地规划文档约定

本目录的规划与交接文件仅供本机 Agent 会话使用，不作为公开仓库中的授权或证据原件。仓库只跟踪本 `README.md`（目录规则），其余内容由根目录 `.gitignore` 忽略；本文件不是 plan 文档。

## 文件命名

plan 文档统一使用 `YYYY-MM-DD_NNN_<topic>.md`：日期取**首次创建日**，`NNN` 为当日从 `001` 开始递增的三位序号，`topic` 用简短的小写英文连字符描述主题。新建前检查当天现有编号，不复用编号；后续修改不重置创建日期或序号。本规则不以任何真实私有文件名作示例。

向 Agent 交接时可在会话中提供本地路径；被 Git 跟踪或拟入库的文件不得引用这里的私有规划文件名、具体路径或以代称引用其内容。需要公开可复取的说明时，另行制作经核对的公开版；不要强制暂存被忽略的文件。
